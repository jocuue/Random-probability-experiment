# Random Number Probability Experiment

A small Python project that generates random numbers from 0–100
and measures how often a chosen number appears over a set number
of attempts.

## What it does

1. The user chooses a target number.
2. The user chooses the maximum number of attempts.
3. The program generates random numbers.
4. It counts how many times the target appears.
5. Probability and Maximum amount of attempts are plugged into a plot.
6. Multiples trials: The user picks how many times to run the experiment, with a separate attempt count each trial.
7. Fraction output: The program prints each trial's experiment probability into a simplified version, labeled with its trial number.

## Current concepts

## How to run

1. Install python
2. Download the project and make sure all 3 folders are in the same folder.
3. Open a terminal in that folder, then install the two required libraries.
py -m pip install numpy matplotlib
4. Start the program
5. Follow the prompts: choose a target from 1-100, choose 1-20 trials, and enter 1-20000 attempts for each trial.
